# apprendre-c

Exercises from *C Programming: A Modern Approach* (K.N. King), on my path toward Embedded Linux.

All code is compiled with:

```
gcc -Wall -Wextra -std=c99 -g
```

## Build

```
make SRC=semaine-01/ch02/pun.c
make run SRC=semaine-01/ch02/pun.c
```

## Layout

One folder per week, one subfolder per chapter. The roadmap is in `docs/roadmap.md`.
